4.2.3 Generic Entity API

Để tránh lặp code, hệ thống định nghĩa ENTITY_CONFIG map từng entity
sang config truy vấn:

  // entity.js (rút gọn)
  const ENTITY_CONFIG = {
    exams: {
      table:      'exams',
      searchCols: ['title', 'exam_code'],
      filterCols: ['teacher_id', 'status', 'class_id'],
      joins:      'LEFT JOIN classes c ON exams.class_id = c.id',
      select:     'exams.*, c.name AS class_name',
    },
    submissions: {
      table:      'submissions',
      searchCols: ['student_name'],
      filterCols: ['exam_id', 'status'],
      joins:      'LEFT JOIN exams e ON submissions.exam_id = e.id',
      select:     'submissions.*, e.title AS exam_title',
    },
    // ...
  }

  router.get('/:entity', requireAuth, async (req, res) => {
    const config = ENTITY_CONFIG[req.params.entity]
    if (!config) return res.status(404).json({ error: 'Not found' })
    const { rows } = await db.query(buildSelectQuery(config, req.query))
    res.json(rows)
  })

4.2.4 Upload File và Trigger n8n

Khi giáo viên upload đề thi, ExpressJS xử lý file bằng multer rồi
trigger workflow n8n ngay sau khi lưu metadata:

  // exams.js (rút gọn)
  router.post('/:id/upload', requireAuth, upload.fields([
    { name: 'question_file' },
    { name: 'answer_file' }
  ]), async (req, res) => {
    // 1. Lưu file path vào PostgreSQL
    await db.query(
      'UPDATE exams SET file_path=$1, answer_path=$2 WHERE id=$3',
      [req.files.question_file[0].path,
       req.files.answer_file[0].path, req.params.id]
    )
    // 2. Trả response ngay (Fire-and-Forget)
    res.json({ success: true, message: 'Processing in background' })
    // 3. Trigger n8n webhook bất đồng bộ
    fetch(process.env.N8N_BASE_URL + '/webhook/upload-exam-api', {
      method: 'POST',
      body: JSON.stringify({ exam_id: req.params.id, ...req.body })
    })
  })


4.3 XÂY DỰNG AI WORKFLOW BẰNG N8N
------------------------------------

4.3.1 Tích hợp Mistral OCR

Quy trình OCR một file PDF qua Mistral API:

  Bước 1 — Upload file lên Mistral:
    POST https://api.mistral.ai/v1/files
    Content-Type: multipart/form-data
    → Response: { file_id, expires_at }

  Bước 2 — Lấy signed URL:
    GET https://api.mistral.ai/v1/files/{file_id}/url
    → Response: { url }

  Bước 3 — Gọi OCR model:
    POST https://api.mistral.ai/v1/ocr
    Body: { model: "mistral-ocr-latest", document: { url } }
    → Response: { pages: [{ markdown }] }

  Bước 4 — Ghép Markdown từ tất cả pages:
    full_text = pages.map(p => p.markdown).join('\n\n')

< ẢNH: Node cấu hình Mistral OCR trong n8n (HTTP Request node) >

4.3.2 Tích hợp GPT-4.1-mini — Structured Extraction

Sau OCR, GPT phân tích Markdown thành JSON có cấu trúc.

Prompt trích xuất đáp án (rút gọn):

  "Phân tích nội dung sau và trả về JSON theo format:
   {
     'questions': [{
       'id': 1,
       'content': '...',
       'correct_answer': '...',
       'max_score': 1.0,
       'rubric': '...'
     }]
   }
   Nội dung đáp án:
   {{$json.ocr_text}}"

Prompt chấm điểm (rút gọn):

  "Chấm bài theo rubric sau. Với mỗi câu hỏi, cho điểm và nhận xét.
   Đáp án: {{$json.answer_extract}}
   Bài làm sinh viên: {{$json.submission_extract}}
   Trả về JSON: {
     'scores': [{ 'question_id', 'score', 'comment' }],
     'total_score': ...,
     'overall_feedback': '...'
   }"

4.3.3 Workflow auto_grade — Chi tiết triển khai

Workflow chạy cron 0 * * * *, xử lý theo batch để tránh timeout:

  [Schedule Trigger]
       ↓
  [PostgreSQL Query]
    SELECT s.id, s.submission_extract,
           e.answer_extract, e.total_score
    FROM   submissions s
    JOIN   exams e ON s.exam_id = e.id
    WHERE  s.status = 'extracted'
      AND  e.status = 'active'
      AND  NOT EXISTS (
             SELECT 1 FROM grading_results gr
             WHERE gr.submission_id = s.id
               AND gr.status != 'regrade_requested'
           )
    LIMIT  10
       ↓
  [Split in Batches] — xử lý từng bài
       ↓
  [OpenAI GPT-4.1-mini] — grading prompt
       ↓
  [Code Node] — parse JSON, tính total_score
       ↓
  [PostgreSQL INSERT]
    INSERT INTO grading_results
      (submission_id, exam_id, total_score, feedback,
       grading_detail, attempt_no, graded_by)
    VALUES (...)
    ON CONFLICT (submission_id, attempt_no) DO UPDATE ...
       ↓
  [PostgreSQL UPDATE]
    UPDATE submissions SET status='graded' WHERE id=...
       ↓
  [system_logs INSERT]

  | API Endpoint               | Chức năng                        |

  | GET  /api/exam-periods     | Danh sách đợt thi                |
  | POST /api/exam-periods     | Tạo đợt thi mới                  |

  | DELETE /api/exam-periods/:id | Xóa đợt thi                   |

  id, period_code, name, start_date, end_date,
  description, teacher_id, created_at

tạo và chỉnh sửa đợt thi trực tiếp qua modal form.

4.6 TRIỂN KHAI HỆ THỐNG
-------------------------
Hệ thống được triển khai bằng Docker Compose với 3 service:

  docker-compose.yml:
  ┌─────────────────────────────────────────────────┐
  │  services:                                      │
  │    api:                                         │
  │      image: node:20-alpine                      │
  │      ports: ["3010:3010"]                       │
  │      env_file: .env                             │
  │      depends_on: [postgres]                     │
  │                                                 │
  │    postgres:                                    │
  │      image: postgres:15                         │
  │      volumes: [pgdata:/var/lib/postgresql/data] │
  │                                                 │
  │    n8n:                                         │
  │      image: n8nio/n8n                           │
  │      ports: ["5678:5678"]                       │
  │      volumes: [n8n_data:/home/node/.n8n]        │
  │      env_file: .env                             │
  └─────────────────────────────────────────────────┘

Các bước triển khai:
  1. Clone repo, tạo file .env từ .env.example
  2. docker compose up -d
  3. Truy cập n8n (localhost:5678), import 3 workflow JSON
  4. Cấu hình credentials: OpenAI, Mistral, Google Drive
  5. Activate các workflow
  6. Truy cập hệ thống tại localhost:3010
